ULTIMATUM GAME VISUALIZER - INSTRUCTIONS
=========================================

QUICK START
-----------

1. Navigate to this directory:
   cd NegotiationArena-main/ultimatum_webapp

2. Install dependencies:
   pip install -r requirements.txt

3. Run the app:
   python run.py

   OR on Mac/Linux:
   ./run.sh

   OR directly:
   streamlit run app.py

4. Open browser at: http://localhost:8501


USING THE APP
-------------

PANEL 1 (Sidebar):
- Enter the path to your log directory
- Select Model A, Model B, and Behavior from dropdowns
- The combination will be automatically selected

PANEL 2 (Conversation Viewer):
- Click buttons 1-10 to select iteration
- Toggle between "Parsed" and "Raw Log" views
- Parsed view shows formatted conversation with:
  * Red boxes = Player RED
  * Blue boxes = Player BLUE
  * Gray boxes = Game START/END
  * Collapsible reasoning sections

PANEL 3 (Summary Statistics):
- Shows raw data from summary.json
- All metrics displayed as key: value pairs


REQUIREMENTS
------------
- Python 3.8+
- streamlit >= 1.28.0
- pandas >= 2.0.0


DIRECTORY STRUCTURE EXPECTED
-----------------------------
.logs/ultimatum_social_behavior_YYYYMMDD_HHMMSS/
├── summary.json
├── Model1_vs_Model2_Behavior_iter_1/
│   └── [timestamp]/
│       ├── game_state.json
│       └── interaction.log
├── Model1_vs_Model2_Behavior_iter_2/
└── ... (more iterations)


TROUBLESHOOTING
---------------

Problem: "Directory not found"
Solution: Check the path is correct and contains summary.json

Problem: "No combinations found"
Solution: Verify iteration folders follow naming pattern

Problem: Port already in use
Solution: Run with different port: streamlit run app.py --server.port 8502

Problem: App won't start
Solution: Check Python version >= 3.8 and dependencies installed
